1) ask - предлагает текстовое решение вопроса
2) code - модифицирует файл Readme
3) debug - т.к. code уже модифицировал файл, отвечает, что уже есть соответствующие строки и задаёт вопрос об уточнении, что ещё надо сделать
4) plan - генерирует файл с планом, где также пишет, что раздел уже есть и спрашивает, что делать дальше
