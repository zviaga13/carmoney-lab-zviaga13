# README: раздел «Как проверить, что сервис жив»

## Текущее состояние

Раздел **уже есть** в `README.md:36-56` и покрывает:

- `make up` печатает URL и health-эндпоинт после старта (`Makefile:19`).
- Три способа проверки:
  - `make ps` — состояние контейнеров `backend` и `db` (`Makefile:24-25` → `docker compose ps`).
  - `make logs` — хвост логов backend, `Ctrl+C` для выхода (`Makefile:27-28`).
  - `curl http://localhost:8080/health` — ожидается `{"status":"ok"}` (роут в `backend/src/AppFactory.php:48-51`, отвечает JSON `{status, service}`).
- Подстановка порта через `${APP_PORT:-8080}` (порт задан в `docker-compose.yml:13-15`).
- Troubleshooting: MySQL ещё не поднялась (healthcheck `interval: 5s, retries: 20` ≈ до 100 с, `docker-compose.yml:38-42`) или порт занят на хосте.
